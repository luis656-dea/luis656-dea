# Ethics of the Metaverse Workplace

Static GitHub Pages website for Luis Couttolenc's creative project.

## Files

- `index.html` is the website entrypoint.
- `styles.css`, `app.js`, and `data.js` power the static site.
- `assets/slides/` contains the 12 presentation slide images.
- `downloads/` contains the original PowerPoint and Word documents.

## GitHub Pages

Upload everything in this folder to a GitHub repository. In GitHub Pages settings, publish from the repository root. No npm install, build step, or backend is required.
